# GDS plugin for Claude Code

Makes Claude Code build UI with the Gjirafa Design System correctly, in your own repo.

| Part | What it does |
|---|---|
| **Skill `gds-ui`** | Loads when you build UI with GDS: setup, the three GDS principles and the workflow. |
| **Skills `gds-<component>`** | One per component contract (`gds-table`, `gds-badge`, …): exact markup, anatomy, modifiers, a11y and rules. Claude loads only the ones the screen needs. |
| **Lint hook** | After every Write/Edit of a `.vue` or `.html` file that uses `gds-` classes, checks the markup against the GDS component contracts. Problems go back to Claude (exit 2), which fixes them. Messages name the rule and often the right class: `did you mean .gds-table?` |

## Install

```
/plugin marketplace add fitpica/gjirafa-design-system
/plugin install gds@gjirafa
```

Or from a terminal:

```bash
claude plugin marketplace add fitpica/gjirafa-design-system
claude plugin install gds@gjirafa
```

Update later with `/plugin update gds@gjirafa` (or turn on auto-update for the `gjirafa` marketplace in `/plugin`). The plugin version matches the GDS version.

## Lint without Claude

```bash
node ~/.claude/plugins/cache/gjirafa/gds/<version>/scripts/gds-lint.mjs src/components/EntriesTable.vue
```

Needs Node 18+. No dependencies.

## What it checks today

All 26 GDS components have contracts. Their structure (classes exist, correct nesting, required children, required modifiers, one size/variant) and 19 design rules for table, pagination, checkbox, badge, input and dropdown (accessible names, sort state, status colours, input size, pagination markup…). The other rules in the contracts guide Claude through the skills but are not linted yet.

Only static `class="…"` attributes are checked; classes bound with `:class` are skipped.

## For GDS maintainers

Most files here are generated by `npm run plugin` (part of `npm run build`) from the contracts in `components/`, `scripts/lib/lint-core.mjs` and `scripts/templates/gds-ui-skill.md`. Edit those, not the copies. Hand-written: `hooks/hooks.json`, `scripts/gds-lint.mjs`, this README. CI fails if the generated files are out of date.
