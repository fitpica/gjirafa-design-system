Build an "All Entries" screen for a content management system as one static HTML file named `index.html`.
- Page header "All Entries" with a primary "New entry" button.
- A toolbar: search input, a filter for status, a filter for content type.
- A data table: select checkbox, Title, Content type, Status (Published / Draft / Scheduled / Archived), Author (with avatar), Last updated. Title and Last updated are sortable; Last updated is sorted descending.
- 8 example rows, 2 of them selected, plus a bulk-action bar for the selection ("2 selected", Publish, Delete).
- Pagination at the bottom.
Use the Gjirafa Design System (GDS) for everything and load it from the CDN.
