Build a "Settings" page for a content management system as one static HTML file named `index.html`.
- Tabs: General, Notifications, Team. Show the Notifications tab selected.
- In Notifications: three on/off settings (Email on publish, Weekly digest, Mentions), a choice of digest day (Monday / Wednesday / Friday, one only), and a saved confirmation message after the form.
- An informational alert at the top: "Changes apply to all editors in this workspace."
- A "Save changes" primary button and a "Reset" secondary button.
Use the Gjirafa Design System (GDS) for everything and load it from the CDN.
