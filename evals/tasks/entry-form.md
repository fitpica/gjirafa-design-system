Build an "Edit entry" form for a content management system as one static HTML file named `index.html`.
- Fields: Title (required), Slug (with a fixed "/news/" prefix), Summary (multi-line, 200 characters max with a counter), Status (choose one of Published / Draft / Scheduled / Archived), Content type (dropdown), Tags (several can be chosen), "Feature on homepage" (on/off setting that applies immediately), Author.
- Show the Title field in an error state with the message "Title is required".
- Buttons: Save (primary), Cancel, and a destructive "Delete entry" that opens a confirmation dialog (render the dialog open).
Use the Gjirafa Design System (GDS) for everything and load it from the CDN.
